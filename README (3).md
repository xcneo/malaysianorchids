# Peninsular Malaysia Orchids Quiz

A single-page game that pulls random research-grade, openly licensed orchid photos
from iNaturalist (Peninsular Malaysia) and tests whether you can name the genus and species.

- **Type it (hard):** enter genus and species epithet. 1 point each, hints cost points.
- **Multiple choice (easy):** pick the right species from 4 options.

No build step or API key. It calls the public iNaturalist API from the browser.

## Run locally

Open `index.html` in a browser (or `python3 -m http.server`).

## Credits

Photos and identifications belong to their iNaturalist observers; each photo's attribution is shown in-game.
